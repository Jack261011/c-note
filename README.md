- 2026-09-18：Day 3 学数据类型与变量。两个发现：① 17/5=3——两边都是整数时是整数除法，小数被直接砍掉，17.0/5 才是 3.4；② float 存 459.99 打出来是 459.989990——二进制写不完这个数，浮点天生有误差，%.2f 只能保证从表面上来看是精确的，但是多次运算之后依然可能会有较大的误差，最好使用double。

- 2026-10-08：Day 5 学 for/while 循环，1~n 求和两种写法结果一致，倒序打印。阶乘实验：13! 打出来是 1932053504 而不是 6227020800。因为int 上限是 2147483647，溢出后按 2^32 环绕，这个数每次运行都不变，它不是随机数
